# แผนผังวางป้าย

เตรียมไว้ 3–4 ชุดที่ความยากใกล้เคียงกัน (จำนวนทางเลี้ยว ระยะทาง และจำนวนป้าย STOP พอ ๆ กัน) แต่ละชุดวางเสาป้าย 5–6 จุด

ตั้งชื่อไฟล์เป็น `layout_A.md`, `layout_B.md`, ...

## หลักการวางป้าย

> ร่างจากกติกาใน [docs/competition-rules.md](../../docs/competition-rules.md) ยังไม่ได้ทดสอบกับหุ่นยนต์จริง ระยะที่กล้องอ่านป้ายทันดูได้จาก checklist ใน [docs/sign-specs.md](../../docs/sign-specs.md)

### ทุกป้าย

- วางมุมเดียวกันของสี่เหลี่ยมสีเขียวทุกจุด เช่น มุมซ้ายด้านไกล (ฝั่งที่เลยจุดตัดไป) หันหน้าป้ายเข้าหาทิศที่รถวิ่งเข้ามา ถ้าวางมุมด้านใกล้ ป้ายจะหลุดเฟรมก่อนรถถึงจุดตัด
- START: วางรถบนเส้นคอลัมน์ A, B หรือ C ช่วงระหว่างเส้นแนวนอนด้านบนกับจุดเขียวแถว 4 หันหน้าลงใต้ จุดตัดแรกที่รถเจอจะเป็นจุดเขียว ไม่ใช่จุดตัดดำ
- ป้ายแรกไม่วางที่จุดตัดแรกหลัง START ให้รถเดินตามเส้นจนนิ่งก่อน
- อย่าวางป้ายที่จุดตัดติดกันในแนวที่กล้องเห็นพร้อมกันในเฟรมเดียว รถจะอ่านป้ายของจุดถัดไปก่อนถึงเวลา
- จุดตัดบนเส้นทางที่ต้องวิ่งตรงไม่ต้องวางป้าย เพราะกติกากำหนดให้จุดตัดที่ไม่มีป้ายตรงไปเสมอ
- จุดเขียวบนเส้นทางที่ถ้าวิ่งตรงไปแล้วจะออกนอกโซนเขียว ต้องมีป้ายเสมอ (ยกเว้นจุด PARKING) เพราะกติกาไม่ได้กำหนดว่ารถต้องทำอะไรที่จุดตัดดำ

### แต่ละชนิด

| ป้าย | ควรวางที่ | ห้ามวางที่ |
| :--- | :--- | :--- |
| เลี้ยวซ้าย / ขวา | จุดตัดบนเส้นทางที่ต้องเปลี่ยนทิศจริง ทั้งทางแยก + และตัว T | จุดที่ฝั่งนั้นไม่มีเส้น หรือเลี้ยวแล้วไปเจอขอบสนาม |
| ตรงไป | จุดตัดที่ดูน่าเลี้ยว เช่น ทางแยก + ที่ต่อจากการเลี้ยว เพื่อดักโค้ดที่เลี้ยวทุกจุดเขียว | ตัว T ที่ไม่มีทางตรง |
| STOP | จุดตัดที่มีทางตรงต่อไปได้ หยุดครบ 3 วินาทีแล้ววิ่งตรงต่อ | ตัว T ที่ไม่มีทางตรง และจุดตัดก่อน PARKING |
| PARKING | จุดเขียวแถว 1 ที่รถวิ่งลงใต้ผ่าน แล้วไปจอดที่ตัว T ขอบล่าง 1 ป้ายต่อชุด | ที่อื่นนอกจากปลายทาง |

### สัดส่วนต่อชุด

ให้ทุกชุดมีสัดส่วนใกล้กันตามนี้ เพื่อให้ความยากพอ ๆ กัน

| ป้าย | จำนวนต่อชุด |
| :--- | :---: |
| เลี้ยวซ้าย + เลี้ยวขวา | 2 หรือ 4 (รถออกจาก START และเข้าจอดโดยหันลงใต้ทั้งคู่ จึงเลี้ยวได้แค่เลขคู่) |
| ตรงไป | 1 ขึ้นไป |
| STOP | 1–2 |
| PARKING | 1 |

## ตรวจแผนผังก่อนใช้

- [ ] ไล่เส้นทางจาก START ทีละจุดตัด ทุกจุดต้องตัดสินได้ทางเดียวจาก "ทำตามป้าย หรือตรงไปถ้าไม่มีป้าย" และต้องไปจบที่ PARKING
- [ ] เส้นทางไม่วนกลับมาจุดตัดเดิม (ป้ายที่วางไว้ใช้ได้กับทิศเดียว)
- [ ] ไม่มีป้ายที่อยู่นอกเส้นทางแต่กล้องมองเห็นได้จากเส้นทาง
- [ ] ป้ายแต่ละชนิดในชุดนี้ไม่เกินจำนวนหน้าป้ายที่พิมพ์ไว้ (ใช้ทีละชุด จึงนับแยกชุด ไม่ต้องรวมทุกชุด)
- [ ] วิ่งเส้นทางนี้ด้วยหุ่นยนต์ของทีมงานจบใน 90 วินาที

## Template `layout_X.md`

```markdown
# Layout X

ผังสนาม: (แนบภาพหรือวาด grid แล้วระบุพิกัดจุดตัด จุดเขียวเรียกเป็นคอลัมน์ A–C จากซ้ายไปขวา และแถว 1–4 จากล่างขึ้นบน)

| ลำดับบนเส้นทาง | จุดตัด | ทิศที่รถวิ่งเข้า | ป้าย |
| :---: | :---: | :---: | :--- |
| 1 | B2 | เหนือ | เลี้ยวขวา |
| 2 | ... | ... | ... |
| ปลายทาง | ... | ... | PARKING |

สรุป: ซ้าย _ / ขวา _ / ตรง _ / STOP _ / PARKING 1
```

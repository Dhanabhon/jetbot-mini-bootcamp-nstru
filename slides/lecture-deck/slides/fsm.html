Module 6 · State Machine

อ่านป้ายก่อน แล้วค่อยทำที่จุดเขียว

STATE 1

เดินตามเส้น

PID ทำงานตลอด กล้องคอยมองหาป้ายข้างหน้า

STATE 2 · Pre-fetch

เห็นป้าย

จำชื่อป้ายไว้ โชว์บน OLED และส่งเสียง Buzzer

STATE 3 · Trigger

เจอสีเขียว

ถึงจุดตัดแล้ว ใช้ป้ายที่จำไว้ตัดสินใจ

STATE 4

ทำตามป้าย

เลี้ยว ตรงไป หยุด 3 วินาที หรือจอด

ทำเสร็จ

ล้างป้ายที่จำไว้ แล้วกลับไป STATE 1 · ถ้าป้ายคือ PARKING ให้หยุดรถและจบโปรแกรม

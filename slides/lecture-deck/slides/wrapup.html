ขอบคุณผู้เข้าอบรม เปิดให้ถามคำถาม ย้ำให้ทุกคน shutdown รถก่อนปิดสวิตช์ และวันแข่งให้นำรถ แบตที่ชาร์จเต็ม และสาย USB มาด้วย การ์ดขวาสุดคือทางลัดหลังอบรม: บน Terminal ของหุ่นยนต์ให้ cd ~/jetbot-mini-bootcamp-nstru แล้วรัน python3 jetbot_app.py จากนั้นเปิด http://10.42.0.1:8080 ทุก module (ตรวจเครื่อง trim เส้น PID ป้าย ภารกิจ) อยู่เป็นแท็บในหน้าเดียว ใช้ค่าจาก my_params.json ไฟล์เดียวกับ notebook ส่วน :8080/live เปิดค้างบนโปรเจกเตอร์ได้ เห็นภาพกล้อง จอ OLED และ Net Time แต่สั่งรถไม่ได้ และไม่ช่วยให้รถวิ่งต่อถ้าปิดหน้าควบคุม ต้องปิด kernel ของ notebook ก่อนเพราะกล้องเปิดได้ทีละโปรแกรม ถ้ารู้วันแข่งแล้วให้แก้ข้อความ "รอประกาศวันที่" ในสไลด์นี้

# ทุกเฟรม (ตัวอย่างแนวคิด)

error = cx - center_x

turn = Kp * error + Kd * (error - prev_error)

base = FAST if abs(error) < STRAIGHT_BAND else SLOW

robot.set_motors(base + turn, base - turn)

prev_error = error

Kp ดึงกลับเข้าเส้น

มากไปรถส่ายซ้ายขวา น้อยไปเลี้ยวไม่ทัน

Kd กันส่าย

ดูว่า error เปลี่ยนเร็วแค่ไหน แล้วเบรกการเลี้ยวไว้ก่อน

Dynamic Speed

ทางตรงเร่งเต็มที่ เข้าโค้งชะลอเอง

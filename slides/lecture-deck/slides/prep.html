ก่อนเขียนโค้ดบรรทัดแรก · พิมพ์ใน Terminal ของ Jupyter Lab

4 คำสั่งที่ต้องรู้ ไม่งั้นรถจะทำตัวแปลก

1 · ปิดโปรแกรม APP ของ Yahboom

sudo systemctl stop jetbotmini_start

โปรแกรมนี้จับมอเตอร์และกล้องไว้ตั้งแต่เปิดเครื่อง ถ้าไม่ปิด โค้ดของเราจะแย่งอุปกรณ์กับมัน

2 · ตั้ง power mode เป็น MAXN

sudo nvpmodel -m0

โหมด 5W ใช้ CPU แค่ 2 core งาน vision จะช้าลงมาก เช็กโหมดปัจจุบันด้วย nvpmodel -q

3 · ก่อน Module 6: ปล่อยจอ OLED

sudo systemctl stop jetbotmini_stats

จด IP ไว้ก่อน หลังสั่งแล้วจอจะไม่แสดง IP อีก แต่โค้ดของเราเขียนชื่อป้ายลงจอได้

4 · ปิดเครื่องทุกครั้ง

sudo shutdown -h now

รอไฟบนบอร์ดดับแล้วค่อยปิดสวิตช์ ถ้าตัดไฟทันที รอบหน้ากล้องอาจเปิดไม่ได้

JetBot Mini Bootcamp @ NSTRU

เปิด Terminal จากเมนู File > New > Terminal ใน Jupyter Lab คำสั่ง stop มีผลแค่รอบนี้ เปิดเครื่องใหม่โปรแกรม APP จะกลับมา ถ้าจะปิดตลอดช่วงอบรมให้ใช้ sudo systemctl disable jetbotmini_start แล้วเปิดคืนภายหลังด้วย enable ข้อ 3 ยังไม่ต้องทำตอนนี้ ให้กลับมาดูหน้านี้ตอนเริ่ม Module 6 ข้อ 4 ย้ำทุกครั้งก่อนพักและก่อนเลิก

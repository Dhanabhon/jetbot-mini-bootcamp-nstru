ก่อนเขียนโค้ดบรรทัดแรก · พิมพ์ใน Terminal ของ Jupyter Lab

4 คำสั่งที่ใช้บ่อยใน Terminal

1 · เข้า folder ของ bootcamp

cd ~/jetbot-mini-bootcamp-nstru

Terminal เปิดที่ folder นี้อยู่แล้ว ใช้เมื่อเปลี่ยนไป folder อื่นแล้วจะกลับมา

2 · แก้ notebook จนเสีย อยากเริ่มใหม่

git checkout -- notebooks/<ชื่อไฟล์>

notebook กลับเป็นฉบับเริ่มต้น ทุกอย่างที่แก้ไว้ในไฟล์นั้นจะหาย ปิด notebook นั้นก่อนสั่ง

3 · ก่อน Module 6: ปล่อยจอ OLED

sudo systemctl stop nstru_status

จอจะไม่แสดงชื่อ Wi-Fi และรหัสอีก คอมพิวเตอร์ที่ต่ออยู่ใช้ต่อได้ แล้วโค้ดของเราเขียนชื่อป้ายลงจอได้

4 · ปิดเครื่องทุกครั้ง

sudo shutdown -h now

รอไฟบนบอร์ดดับแล้วค่อยปิดสวิตช์ ถ้าตัดไฟทันที รอบหน้ากล้องอาจเปิดไม่ได้

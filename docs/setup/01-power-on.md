# เปิดและปิดเครื่อง

## ก่อนเปิดเครื่อง

- ตรวจว่ามี storage ของระบบเสียบอยู่: รุ่น Jetson Nano 2GB ใช้ SD card ที่ช่องด้านหลังบอร์ด ส่วนรุ่น 4GB ใช้ USB drive ที่ Yahboom ให้มา
- แบตเตอรี่ชาร์จแล้ว
- วางหุ่นยนต์บนพื้นหรือยกล้อลอยไว้ กันรถวิ่งตกโต๊ะ

## เปิดเครื่อง

1. เปิดสวิตช์ power ของหุ่นยนต์
2. รอ 2–3 นาทีให้ระบบ boot
3. เมื่อ boot เสร็จจะมีสัญญาณต่อไปนี้
   - Buzzer ดัง 3 ครั้ง
   - ไฟ status กะพริบ
   - ไฟสีเขียวและไฟ 3.3V ติดค้าง
   - จอ OLED แสดงชื่อ Wi-Fi ของหุ่นยนต์ รหัส ที่อยู่ `10.42.0.1:8888` และแรงดันแบต (หุ่นยนต์ที่ผ่าน[ขั้นที่ 0](00-first-setup.md)แล้ว)

   ตำแหน่งของไฟแต่ละดวงดูที่[ผังบอร์ดขยาย](expansion-board.md)

ถ้ารอเกิน 3 นาทีแล้วยังไม่มีสัญญาณ ให้ปิดแล้วเปิดเครื่องใหม่

## ปิดเครื่องให้ถูกวิธี

สั่ง shutdown ก่อนปิดสวิตช์ทุกครั้ง การตัดไฟทันทีอาจทำให้กล้องเรียกใช้งานไม่ได้ในครั้งถัดไป สั่งใน Terminal ของ Jupyter Lab ได้เลย

```bash
sudo shutdown -h now
```

รอจนไฟบนบอร์ด Jetson Nano ดับ แล้วค่อยปิดสวิตช์

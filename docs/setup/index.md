| ขั้น | ทำอะไร | ใช้เวลา |
| :--- | :--- | :--- |
| 1 | [เปิดเครื่องและตรวจสัญญาณ boot](01-power-on.md) | 3 นาที |
| 2 | [ต่อสาย USB แล้ว SSH เข้าหุ่นยนต์](02-usb-ssh.md) | 5 นาที |
| 3 | [ต่อ Wi-Fi ของห้องอบรม](03-wifi.md) | 3 นาที |
| 4 | [เข้า Jupyter Lab และเตรียมพร้อมเขียนโค้ด](04-jupyter-lab.md) | 5 นาที |

ติดขัดตรงไหน ดูที่ [แก้ปัญหาการเชื่อมต่อ](troubleshooting.md)

## ภาพรวม

หุ่นยนต์เชื่อมกับคอมพิวเตอร์ได้ 2 ทาง

| ทาง | ที่อยู่ของหุ่นยนต์ | ใช้ตอนไหน |
| :--- | :--- | :--- |
| สาย USB (headless mode) | `192.168.55.1` เสมอ | ตั้งค่าครั้งแรก หรือเมื่อ Wi-Fi มีปัญหา |
| Wi-Fi ของ router ห้องอบรม | IP บนสติ๊กเกอร์ที่ตัวรถ (หรือจอ OLED) | ใช้งานจริงตลอดการอบรม เพราะหุ่นยนต์ต้องวิ่งได้อิสระ |

## ข้อมูล login

ใช้กับ image ที่ Yahboom ติดตั้งมาให้

| รายการ | ค่า |
| :--- | :--- |
| Username | `jetson` |
| Password (ทุกจุดในระบบ รวมถึง Jupyter Lab) | `yahboom` |
| Jupyter Lab | `http://<IP>:8888` |

เนื้อหาส่วนนี้เรียบเรียงจาก[คู่มือ JetBot Mini ของ Yahboom](https://www.yahboom.net/study/JETBOT-mini) บทที่ 2.2, 2.3, 3.1, 3.3 และ 4.1

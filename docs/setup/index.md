# การเชื่อมต่อหุ่นยนต์กับคอมพิวเตอร์

ในวันอบรม เริ่มที่[ขั้นที่ 0](00-first-setup.md) ทำพร้อมผู้สอนครั้งเดียว จบขั้นนี้แล้วหุ่นยนต์จะเปิด Wi-Fi ของตัวเอง และคอมพิวเตอร์ของเราเข้า Jupyter Lab ได้เลย ครั้งต่อไปแค่เปิดหุ่นยนต์ ต่อ Wi-Fi `JETBOT-NN` แล้วเปิด `http://10.42.0.1:8888`

| ขั้น | ทำอะไร | ใช้เวลา |
| :--- | :--- | :--- |
| 0 | [ตั้งค่าหุ่นยนต์ครั้งแรก แล้วต่อ Wi-Fi ของหุ่นยนต์](00-first-setup.md) | 20 นาที |
| 1 | [ใช้งาน Jupyter Lab: Terminal, เปิด notebook, ปิดเครื่อง, ส่งไฟล์](04-jupyter-lab.md) | 5 นาที |

อ่านเพิ่มเติม: [เปิดและปิดเครื่อง](01-power-on.md) อธิบายสัญญาณตอน boot

ทางสำรองเมื่อมีปัญหา ไม่ต้องทำในวันอบรมถ้าทุกอย่างปกติ

- [SSH เข้าหุ่นยนต์](02-usb-ssh.md) ผ่าน Wi-Fi ของหุ่นยนต์ หรือผ่านสาย USB เมื่อเปิด Jupyter Lab ไม่ได้
- [ปัญหา Wi-Fi และการต่อ Wi-Fi อื่น](03-wifi.md) เมื่อคอมพิวเตอร์หลุดจาก Wi-Fi ของหุ่นยนต์ หรือจะนำหุ่นยนต์ไปต่อ Wi-Fi ที่บ้าน

ติดขัดตรงไหน ดูที่ [แก้ปัญหาการเชื่อมต่อ](troubleshooting.md)

## ภาพรวม

หุ่นยนต์เชื่อมกับคอมพิวเตอร์ได้ 3 ทาง

| ทาง | ที่อยู่ของหุ่นยนต์ | ใช้ตอนไหน |
| :--- | :--- | :--- |
| Wi-Fi ของหุ่นยนต์ `JETBOT-NN` | `10.42.0.1` เสมอ | ใช้งานจริงตลอดการอบรม หลังทำ[ขั้นที่ 0](00-first-setup.md) |
| สาย USB (headless mode) | `192.168.55.1` เสมอ | เมื่อ Wi-Fi มีปัญหา ตาม[ทางสำรอง SSH](02-usb-ssh.md) |
| Wi-Fi ของ router อื่น เช่น ที่บ้าน | IP บนจอ OLED | นำหุ่นยนต์ไปใช้นอกห้องอบรม ตาม[ทางสำรอง Wi-Fi](03-wifi.md#robot-wifi) |

## ข้อมูล login

ใช้กับ image ที่ Yahboom ติดตั้งมาให้

| รายการ | ค่า |
| :--- | :--- |
| Username | `jetson` |
| Password (ทุกจุดในระบบ รวมถึง Jupyter Lab) | `yahboom` |
| Jupyter Lab | `http://<IP>:8888` |

เนื้อหาส่วนนี้เรียบเรียงจาก[คู่มือ JetBot Mini ของ Yahboom](https://www.yahboom.net/study/JETBOT-mini) บทที่ 2.2, 2.3, 3.1, 3.3 และ 4.1

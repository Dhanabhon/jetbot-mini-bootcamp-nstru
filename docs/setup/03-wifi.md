# ขั้นที่ 3: ให้หุ่นยนต์ต่อ Wi-Fi ของห้องอบรม

{% include os-switch.html %}

ทำขั้นนี้ผ่าน SSH ที่เปิดไว้จาก[ขั้นที่ 2](02-usb-ssh.md) หุ่นยนต์และคอมพิวเตอร์ต้องอยู่ Wi-Fi วงเดียวกัน

## สั่งให้หุ่นยนต์ต่อ Wi-Fi

1. ดูรายชื่อ Wi-Fi ที่หุ่นยนต์มองเห็น

   ```bash
   nmcli dev wifi
   ```

2. ต่อ Wi-Fi โดยแทน `ชื่อWiFi` และ `รหัสผ่าน` ด้วยค่าของห้องอบรม

   ```bash
   sudo nmcli dev wifi connect ชื่อWiFi password รหัสผ่าน
   ```

   ถ้าชื่อ Wi-Fi มีช่องว่าง ให้ครอบด้วยเครื่องหมายคำพูด เช่น `"NSTRU Robot"`

3. ระบบจะถาม password ของ `sudo` ให้ใส่ `yahboom`
4. ถ้าสำเร็จจะขึ้นข้อความ `successfully activated`

## หา IP Address ของหุ่นยนต์

ดูได้ 2 ทาง

- **จอ OLED** บนหุ่นยนต์ จะแสดง IP ใหม่ภายในไม่กี่วินาที
- หรือสั่งคำสั่งนี้ แล้วดูบรรทัด `inet` ใต้ `wlan0`

  ```bash
  ifconfig wlan0
  ```

จด IP นี้ไว้ เช่น `192.168.1.196`

## ทดสอบผ่าน Wi-Fi

1. ต่อคอมพิวเตอร์เข้า Wi-Fi วงเดียวกับหุ่นยนต์
2. พิมพ์ `exit` เพื่อออกจาก SSH เดิม แล้ว**ถอดสาย USB**
3. ตรวจว่าคอมพิวเตอร์อยู่วงเดียวกับหุ่นยนต์จริง (ดูวิธีด้านล่าง)
4. SSH ใหม่ด้วย IP ที่จดไว้

   ```bash
   ssh jetson@192.168.1.196
   ```

ถ้าเข้าได้ แปลว่าหุ่นยนต์พร้อมใช้งานแบบไร้สายแล้ว ครั้งต่อไปที่เปิดเครื่อง หุ่นยนต์จะต่อ Wi-Fi นี้เอง

### ดู IP ของคอมพิวเตอร์

โดยทั่วไป IP ของคอมพิวเตอร์ควรขึ้นต้นด้วยตัวเลข 3 ชุดแรกเหมือนหุ่นยนต์ เช่น หุ่นยนต์ได้ `192.168.1.196` คอมพิวเตอร์ควรได้ `192.168.1.xxx` ถ้าไม่ตรง แปลว่าอยู่คนละวง ให้เปลี่ยน Wi-Fi ของคอมพิวเตอร์

<div data-os="windows" markdown="1">

**Windows:** ใน Terminal หรือ PowerShell สั่ง

```powershell
ipconfig
```

ดูบรรทัด `IPv4 Address` ใต้หัวข้อ *Wireless LAN adapter Wi-Fi*

</div>

<div data-os="mac" markdown="1">

**macOS:** ใน Terminal สั่ง

```bash
ipconfig getifaddr en0
```

ถ้าไม่มีอะไรขึ้น (เกิดกับ Mac บางรุ่นที่ Wi-Fi ไม่ใช่ `en0`) ให้ดูที่ System Settings > Wi-Fi > กด **Details** ที่ชื่อ Wi-Fi ที่ต่ออยู่ > TCP/IP

</div>

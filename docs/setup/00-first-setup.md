# ขั้นที่ 0: ตั้งค่าหุ่นยนต์ครั้งแรก

ทำครั้งเดียวตอนเริ่มอบรม โดยทำไปพร้อมกับผู้สอน ใช้เวลาประมาณ 20 นาที เมื่อจบขั้นนี้ หุ่นยนต์จะเปิด Wi-Fi ของตัวเองชื่อ `JETBOT-NN` (`NN` คือหมายเลขหุ่นยนต์ 2 หลัก) แล้วคอมพิวเตอร์ของเราต่อ Wi-Fi นี้เพื่อเข้า Jupyter Lab ได้ทันที ไม่ต้องใช้ router และไม่ต้องใช้ internet

## เตรียมของ

- หุ่นยนต์ที่ชาร์จแบตแล้ว และมีสติ๊กเกอร์หมายเลขหุ่นยนต์
- Wi-Fi dongle เสียบอยู่ที่ช่อง USB ของหุ่นยนต์
- จอที่มีช่อง HDMI, คีย์บอร์ด และเมาส์แบบ USB
- คอมพิวเตอร์ของเรา (ใช้ตอนท้ายขั้นนี้)

ทีมงานคัดลอกโค้ดของ bootcamp และไฟล์รหัส Wi-Fi ลงหุ่นยนต์ทุกตัวไว้ให้แล้ว

## 1. ต่อจอแล้วเปิดเครื่อง

1. ต่อสาย HDMI คีย์บอร์ด และเมาส์เข้าหุ่นยนต์**ก่อน**เปิดเครื่อง จอที่ต่อทีหลังอาจไม่มีภาพ
2. เปิดสวิตช์ power แล้วรอ 2–3 นาทีจนขึ้นหน้า desktop
3. ถ้าขึ้นหน้า login ให้ใส่ password `yahboom`

## 2. เปิดโปรแกรมตั้งค่า

1. เปิด Terminal ด้วยปุ่ม `Ctrl` + `Alt` + `T` ถ้าไม่ขึ้นให้เรียกทีมงาน
2. พิมพ์ 2 คำสั่งนี้ทีละบรรทัด แล้วกด `Enter`

   ```bash
   cd ~/jetbot-mini-bootcamp-nstru
   python3 tools/robot_setup.py
   ```

3. ถ้าถาม `[sudo] password for jetson:` ให้พิมพ์ `yahboom` แล้วกด `Enter` ตอนพิมพ์จะไม่มีตัวอักษรขึ้นบนจอ เป็นเรื่องปกติ

ไม่ต้องใส่ `sudo` หน้าคำสั่ง โปรแกรมจะขอรหัสผ่านเอง

## 3. ทำตามโปรแกรมทีละขั้น

โปรแกรมแบ่งเป็น 10 ขั้น แต่ละขั้นจะบอกว่าทำอะไรและทำไม แล้วรอให้กด `Enter` เพื่อเริ่ม รอผู้สอนบอกก่อนกด `Enter` แต่ละขั้น คำถามที่มี `[y/n]` ให้พิมพ์ `y` (ใช่) หรือ `n` (ไม่ใช่) แล้วกด `Enter`

| ขั้น | โปรแกรมทำอะไร | เราต้องทำอะไร |
| :---: | :--- | :--- |
| 1 | ตรวจบอร์ด หน่วยความจำ พื้นที่ดิสก์ แบต และ Wi-Fi dongle | อ่านผลอย่างเดียว |
| 2 | ตั้งชื่อหุ่นยนต์เป็น `jetbot-NN` | พิมพ์หมายเลขจากสติ๊กเกอร์ เช่น `7` |
| 3 | ตั้งนาฬิกา | เทียบกับเวลาที่ผู้สอนบอก ตรงตอบ `y` ไม่ตรงตอบ `n` แล้วพิมพ์เวลาที่ถูก เช่น `2026-11-23 09:05` |
| 4 | ปิดโปรแกรม APP มือถือของ Yahboom ที่แย่งมอเตอร์และกล้องกับโค้ดของเรา | กด `Enter` |
| 5 | เปิด Wi-Fi `JETBOT-NN` ของหุ่นยนต์ | ตอบ `y` หุ่นยนต์จะหลุดจาก Wi-Fi ที่ต่ออยู่เดิม เป็นเรื่องปกติ |
| 6 | ตั้ง power mode เป็น MAXN ให้ CPU ทำงานครบ 4 core | กด `Enter` |
| 7 | ให้ Jupyter Lab เปิดที่ folder ของ bootcamp | กด `Enter` |
| 8 | ตั้งจอ OLED ให้แสดงชื่อ Wi-Fi รหัส และแบต และให้ Buzzer ดัง 3 ครั้งเมื่อเปิดเครื่องเสร็จ | กด `Enter` |
| 9 | ทดสอบกล้อง Buzzer ล้อ จอ OLED และปุ่ม KEY1 | **ยกล้อให้ลอยจากพื้น**ก่อน แล้วตอบตามที่เห็นและได้ยิน เมื่อโปรแกรมบอก ให้กดปุ่ม KEY1 ภายใน 10 วินาที (ตำแหน่งปุ่มดูที่[ผังบอร์ดขยาย](expansion-board.md)) |
| 10 | สรุปผลทุกขั้น | ตรวจว่าทุกขั้นขึ้น `✓ ผ่าน` |

ถ้าขั้นไหนขึ้น `✗ ไม่ผ่าน` อย่าเพิ่งปิดเครื่อง เรียกทีมงานมาดู ผลทุกครั้งบันทึกไว้ที่ `~/robot_setup.log` หลังแก้ปัญหาแล้ว รันซ้ำเฉพาะขั้นนั้นได้ เช่น ขั้นที่ 5

```bash
python3 tools/robot_setup.py --step 5
```

รันซ้ำกี่รอบก็ได้ ขั้นที่ตั้งค่าไว้แล้วจะขึ้น `✓` และไม่แก้อะไรซ้ำ

## 4. ถอดจอแล้วเปิดเครื่องใหม่

1. เมื่อทุกขั้นผ่าน โปรแกรมจะถามว่า `ปิดเครื่องเพื่อถอดจอเลยไหม` ให้ตอบ `y`
2. รอจนไฟบนบอร์ด Jetson Nano ดับ แล้วปิดสวิตช์ power
3. ถอดสาย HDMI คีย์บอร์ด และเมาส์ออก
4. เปิดสวิตช์ power อีกครั้ง แล้วรอ 2–3 นาที เมื่อพร้อม Buzzer จะดัง 3 ครั้ง และจอ OLED จะแสดง 4 บรรทัด

| บรรทัดบนจอ OLED | ตัวอย่าง | ความหมาย |
| :---: | :--- | :--- |
| 1 | `JETBOT-07` | ชื่อ Wi-Fi ของหุ่นยนต์ |
| 2 | `PW ...` | รหัส Wi-Fi |
| 3 | `10.42.0.1:8888` | ที่อยู่ของ Jupyter Lab |
| 4 | `BAT 12.1V` | แรงดันแบต |

ถ้าจอขึ้น `NO HOTSPOT` หรือ `NO WIFI DONGLE` ให้เรียกทีมงาน

## 5. ต่อคอมพิวเตอร์เข้า Wi-Fi ของหุ่นยนต์

1. ที่คอมพิวเตอร์ของเรา เลือก Wi-Fi ชื่อเดียวกับบรรทัดแรกของจอ OLED เช่น `JETBOT-07` ระวังอย่าต่อหุ่นยนต์ของคนอื่น
2. ใส่รหัสตามบรรทัด `PW` บนจอ OLED
3. ระบบจะขึ้นว่า *No internet* เป็นเรื่องปกติ เพราะ Wi-Fi นี้ต่อกับหุ่นยนต์อย่างเดียว ระหว่างต่อ Wi-Fi นี้ คอมพิวเตอร์จะใช้ internet ไม่ได้

ถ้าไม่เห็นชื่อ Wi-Fi ของหุ่นยนต์ในรายการ ให้เรียกทีมงาน หุ่นยนต์ส่วนใหญ่ใช้คลื่น 5 GHz ซึ่งคอมพิวเตอร์รุ่นเก่าบางเครื่องมองไม่เห็น

ถ้าคอมพิวเตอร์สลับไปต่อ Wi-Fi อื่นเอง ให้ปิดการต่ออัตโนมัติของ Wi-Fi อื่นนั้นตามวิธีใน[ขั้นที่ 3](03-wifi.md)

## 6. เปิด Jupyter Lab

1. เปิด **Google Chrome** แล้วพิมพ์ที่ address bar

   ```text
   http://10.42.0.1:8888
   ```

   หุ่นยนต์ทุกตัวใช้ที่อยู่นี้เหมือนกัน เพราะแต่ละคนต่อ Wi-Fi ของหุ่นยนต์ตัวเอง

2. ใส่ password `yahboom`
3. แถบไฟล์ด้านซ้ายจะแสดง folder ของ bootcamp ดับเบิลคลิกเข้า `notebooks` แล้วเปิด `01_setup_first_trial.ipynb`

ถ้าเปิดได้ แปลว่าพร้อมเริ่มเรียนแล้ว

## ครั้งต่อไปที่เปิดเครื่อง

ไม่ต้องต่อจอและไม่ต้องรันโปรแกรมตั้งค่าอีก แค่เปิดหุ่นยนต์ รอ Buzzer ดัง 3 ครั้ง ต่อคอมพิวเตอร์เข้า Wi-Fi `JETBOT-NN` แล้วเปิด `http://10.42.0.1:8888`

ก่อนปิดสวิตช์ทุกครั้ง ให้สั่ง shutdown ก่อน ตามวิธีใน[ขั้นที่ 1](01-power-on.md)

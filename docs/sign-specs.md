# สเปกเสาป้ายจราจร 3D Printed

ออกแบบให้เข้ากับมุมกล้อง IMX219 (77° FOV) ของ JetBot Mini และขนาดตาราง grid ของสนามจริง

| ส่วน | ขนาด | หมายเหตุ |
| :--- | :--- | :--- |
| หน้าป้าย (Sign Face) | `8.0 x 8.0 ซม.` | ใช้ Matte Sticker เท่านั้น เพื่อลดแสงสะท้อนเข้ากล้อง |
| ระยะจากพื้นถึงขอบล่างป้าย (Ground Clearance) | `8.0 ซม.` | ไม่บังมุมกล้องที่ก้มมองเส้น |
| ความสูงรวมถึงยอดป้าย | `16.0 ซม.` | |
| แกนเสา | `1.5 ซม.` | |
| มุมเอียงหน้าป้าย (Downward Tilt) | ก้มลง `5° – 10°` | ให้หน้าป้ายตั้งฉากกับเลนส์กล้องที่ก้มลง และลดแสงสะท้อนจากไฟเพดาน |
| ฐาน (Heavy Flare Base) | `6.0 x 6.0 ซม.` หนา `0.5 ซม.` | เว้ามุมหนึ่งด้าน เพื่อวางชิดขอบสี่เหลี่ยมสีเขียวได้โดยไม่ทับเส้นดำ |

## Slicer Settings

- Infill ฐาน `40–50%` หรือถ่วงน้ำหนักใต้ฐาน
- Infill ตัวเสา `15–20%`
- Filament โทนด้านหรือทึบ เช่น เทาเข้ม ดำ ขาว

## ไฟล์ที่เกี่ยวข้อง

- `3d_models/` ไฟล์ .stl ของเสาและฐาน
- `stickers/` ไฟล์ภาพป้ายทั้ง 5 แบบสำหรับพิมพ์สติ๊กเกอร์

## ต้องทดสอบกับหุ่นยนต์จริงก่อนพิมพ์ครบชุด

- [ ] ที่มุมก้มกล้องสำหรับเดินตามเส้น กล้องเห็นป้ายเต็มใบที่ระยะกี่ซม. ก่อนถึงจุดตัด
- [ ] ระยะนั้นพอให้อ่านป้ายทันที่ความเร็วแข่งหรือไม่ ถ้าไม่พอ ให้ปรับความสูงเสาหรือมุมเอียงหน้าป้าย

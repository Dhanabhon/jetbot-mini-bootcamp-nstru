# โจทย์และกติกาการแข่งขัน: Smart Grid Autonomous Delivery

แข่งแบบเดี่ยว ผู้เข้าอบรม 10 คน ใช้หุ่นยนต์ของตัวเองคนละ 1 ตัว การแข่งขันจัด 1 วัน แยกจากวันอบรม

การแข่งขันนี้เป็นกิจกรรมภายในกลุ่มผู้เข้าอบรม จัดแบบเป็นกันเอง ไม่มีรางวัล เป้าหมายคือให้ทุกคนได้ลองโค้ดของตัวเองบนสนามจริงและเรียนรู้จากกันและกัน กติกาด้านล่างใช้เป็นแนวทาง กรรมการปรับได้ตามสถานการณ์หน้างาน

ระหว่างวันอบรมกับวันแข่ง ผู้เข้าอบรมนำหุ่นยนต์กลับไปพัฒนาโค้ดต่อเองได้

## กำหนดการวันแข่ง

> ร่างลำดับไว้ก่อน เวลาจริงรอยืนยัน

| ลำดับ | กิจกรรม |
| :--- | :--- |
| 1 | ลงทะเบียน และตรวจสภาพหุ่นยนต์ (Scrutineering) |
| 2 | ซ้อมบนสนามจริง และจูนค่าตามสภาพแสงของวันแข่ง |
| 3 | ทบทวนกติกา และจับฉลากลำดับการแข่ง |
| 4 | Run 1 (10 คน) |
| 5 | พักจูนพารามิเตอร์ 5 นาที |
| 6 | Run 2 (10 คน) |
| 7 | สรุป Net Time และประกาศผล |

## 1. สนามและภารกิจ

- **สนาม:** ไวนิลตาราง grid พื้นขาว เส้นดำ มี **สี่เหลี่ยมสีเขียว (Green Intersection Marker)** บอกตำแหน่งทางแยก และมีโซนจอดปลายทางอยู่ด้านบน
- **ภารกิจ:** เขียนโปรแกรมให้ JetBot Mini วิ่งจาก **START** ไปถึง **DESTINATION** ให้เร็วที่สุด โดยใช้กล้องอ่าน **เสาป้ายจราจร 3D Printed** ที่ตั้งอยู่มุมจุดตัดสีเขียว แล้วเลือกเส้นทางและทำตามป้ายให้ถูกต้อง

## 2. ความหมายของป้าย

เสาป้ายวางที่มุมของสี่เหลี่ยมสีเขียว หันหน้าป้ายเข้าหาทิศที่หุ่นยนต์วิ่งเข้ามา

| ป้าย | ลักษณะ | สิ่งที่หุ่นยนต์ต้องทำ |
| :--- | :--- | :--- |
| เลี้ยวซ้าย | ลูกศรขาวพื้นน้ำเงิน ชี้ซ้าย | เลี้ยวซ้าย 90° ที่จุดตัด แล้วไปตามเส้นดำ |
| เลี้ยวขวา | ลูกศรขาวพื้นน้ำเงิน ชี้ขวา | เลี้ยวขวา 90° ที่จุดตัด แล้วไปตามเส้นดำ |
| ตรงไป | ลูกศรขาวพื้นน้ำเงิน ชี้ตรง | วิ่งข้ามจุดตัดตรงไปด้วยความเร็วเต็มที่ |
| STOP | แปดเหลี่ยมสีแดง | หยุดนิ่งสนิท (ล้อไม่หมุน) **3 วินาที** พร้อมแสดง `STOP` บนจอ OLED แล้ววิ่งข้ามจุดตัดตรงไป |
| PARKING / DELIVERY | ป้ายจุดจอดปลายทาง | เข้าจอดหยุดสนิทที่จุดตัดหรือเส้นตัว T ด้านบน เพื่อจบภารกิจ (หยุดจับเวลา) |

**จุดตัดสีเขียวที่ไม่มีป้าย:** หุ่นยนต์ต้องวิ่งข้ามจุดตัดตรงไปเสมอ ถ้าเลี้ยวที่จุดนี้ถือเป็นเลี้ยวผิดทาง (+10 วินาที)

## 3. กติกา

- **รูปแบบ (Time Trial):** แข่งทีละ 1 คัน คนละ **2 รอบ (Run 1 และ Run 2)** ใช้ Net Time ของรอบที่ดีที่สุดรอบเดียว
- **Time Limit:** รอบละ **90 วินาที** เกินเวลาถือว่าไม่จบการแข่งขัน (DNF)
- **Dynamic Route:** ก่อนเริ่มแต่ละรอบ กรรมการวางเสาป้าย 5–6 จุดตามแผนผังลับ ผู้แข่งมีเวลาดูสนาม 1 นาที และห้ามแก้โค้ด
- **อัตโนมัติ 100%:** เมื่อกดรันโค้ดแล้ว ห้ามใช้จอยสติ๊ก คีย์บอร์ด หรือส่งคำสั่งผ่าน Wi-Fi เข้าไปควบคุมรถ
- **ห้าม hardcode เส้นทาง:** โค้ดต้องตัดสินใจจากภาพกล้องจริงเท่านั้น ถ้ากรรมการสลับป้ายแล้วรถยังวิ่งแพทเทิร์นเดิมโดยไม่สนป้าย จะถูกปรับฟาวล์ในรอบนั้น
- **การแก้โค้ดระหว่างรอบ:** จูนพารามิเตอร์ได้ 5 นาทีในช่วงพักก่อน Run 2

## 4. การคิด Net Time

```text
Net Time = เวลาวิ่งจริง (วินาที) + Penalty − Bonus
```

| เหตุการณ์ในสนาม | ผลต่อเวลา |
| :--- | :--- |
| อ่านป้ายและแสดงชื่อป้ายบนจอ OLED ถูกต้อง (ก่อนทำภารกิจ) | **−2 วินาที / ป้าย** |
| หยุดที่ป้าย STOP ครบ 3 วินาที (ล้อไม่หมุน) | **−2 วินาที / ป้าย** |
| เข้าจอดที่ PARKING สนิท (ล้อหน้าอยู่บนเส้นหรือในช่องจอด) | **−3 วินาที** |
| เลี้ยวผิดทาง หรือฝ่าฝืนป้าย (หยิบกลับมาวางที่จุดแยกเดิมได้) | **+10 วินาที / ครั้ง** |
| รถหลุดออกนอกเส้นดำ (ขอหยิบกลับมาวางบนเส้นจุดล่าสุด) | **+5 วินาที / ครั้ง** (ไม่เกิน 3 ครั้ง/รอบ) |
| ชนเสาป้ายล้ม หรือเลื่อนออกนอกจุด | **+3 วินาที / ครั้ง** |

## 5. ประเด็นที่ยังรอตัดสินใจ

กติกาข้างบนยังไม่ครอบคลุมกรณีต่อไปนี้ เนื่องจากเป็นการแข่งแบบเป็นกันเอง จะสรุปก่อนวันแข่งหรือให้กรรมการตัดสินหน้างานก็ได้

- [ ] วันแข่งมีเวลาซ้อมบนสนามจริงคนละกี่นาที
- [ ] หลุดเส้นครั้งที่ 4 ในรอบเดียวกัน ถือเป็น DNF หรือไม่
- [ ] โทษ "ปรับฟาวล์" กรณี hardcode เส้นทาง คืออะไร (เช่น รอบนั้นเป็น DNF)
- [ ] Net Time เท่ากัน ตัดสินอย่างไร
- [ ] ถ้า DNF ทั้ง 2 รอบ จัดอันดับจากอะไร (เช่น จำนวนป้ายที่ผ่านถูกต้อง)

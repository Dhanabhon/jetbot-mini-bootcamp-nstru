# Stickers

ไฟล์ภาพป้ายจราจรความละเอียดสูงสำหรับพิมพ์สติ๊กเกอร์ ขนาดหน้าป้าย `8.0 x 8.0 ซม.` พิมพ์บน Matte Sticker เท่านั้น

ป้ายทั้ง 5 แบบ: เลี้ยวซ้าย, เลี้ยวขวา, ตรงไป, STOP, PARKING / DELIVERY

## ไฟล์

| ไฟล์ | เนื้อหา |
| :--- | :--- |
| `JetBot_Thai_Traffic_Signs_A4.pdf` | ป้ายไทยครบ 5 แบบในแผ่น A4 เดียว: ให้เลี้ยวซ้าย (บ.43), ให้เลี้ยวขวา (บ.44), ตรงไป (อ้างอิง บ.37), หยุด (บ.1), ที่จอดรถ (สค.1) |

## วิธีพิมพ์

1. สั่งพิมพ์แบบ Actual Size หรือ 100% ปิด Fit / Scale to fit
2. วัดเส้นสเกลด้านล่างของแผ่นให้ได้ 50 มม. ถ้าไม่ได้ แปลว่าเครื่องพิมพ์ย่อหรือขยาย ให้แก้แล้วพิมพ์ใหม่
3. ตัดตามขีดมุม ได้ป้ายละ 80 × 80 มม.

หนึ่งแผ่นได้ป้ายแบบละ 1 ใบ ให้พิมพ์จำนวนแผ่นตามป้ายชนิดที่ต้องใช้มากที่สุดในแผนผังชุดใดชุดหนึ่ง แล้วเผื่อสำรอง
